# 茂智云仓进出仓管理系统 — 操作员操作手册

## 文档说明

- **系统名称**：茂智云仓进出仓管理系统（PC 端 + 微信小程序端）
- **适用对象**：仓库操作员、仓管员、审核员、系统管理员
- **版本信息**：v1.0（后端 wms-backend，Web 前端 wms-frontend-pure，小程序 wms-miniapp）

---

## 1. 系统登录与首页

**功能说明**：登录系统并查看首页数据概览。

**操作步骤**：

1. 打开浏览器，输入系统网址
2. 输入「用户名」和「密码」
3. 点击「登录」按钮
4. 登录成功后进入首页，查看今日入库/出库吨位、总 SKU 数、总吨位等数据卡片
5. 下方显示各仓库实时库存汇总

**常见错误与解决方法**：

| 错误现象               | 可能原因             | 解决方法                           |
| ---------------------- | -------------------- | ---------------------------------- |
| 提示"用户名或密码错误" | 输入错误或账号被禁用 | 检查大小写；联系管理员确认账号状态 |
| 登录后页面空白         | 浏览器缓存或网络问题 | 按 F5 刷新页面；清理浏览器缓存     |
| 首页数据不显示         | 接口加载异常         | 点击页面重试按钮；联系技术支持     |

**注意事项**：

- 首次登录建议修改初始密码
- 离开工位前务必退出登录
- 首页数据可手动刷新，页面提供重试按钮

## 2. 基础资料

### 2.1 商品管理

**功能说明**：维护系统中所有商品（产品）的基本信息。

**操作步骤**：

1. 点击左侧菜单「基础资料」→「商品管理」
2. 查看商品列表，支持按编码/名称搜索
3. **新增商品**：点击「新增」→ 填写必填项（商品编码、名称、型号、计数单位、计重单位）→ 点击「保存」
4. **编辑商品**：在列表中点击「编辑」→ 修改信息 → 点击「保存」
5. **启用/停用**：点击状态开关切换

**常见错误**：

| 错误现象     | 可能原因             | 解决方法               |
| ------------ | -------------------- | ---------------------- |
| 商品编码重复 | 已存在相同编码       | 修改编码或先搜索确认   |
| 必填字段未填 | 表单验证不通过       | 补全所有标红字段       |
| 无法停用商品 | 商品已被出入库单引用 | 先处理完关联单据再停用 |

**注意事项**：

- 商品编码一旦创建不可修改
- 停用的商品无法在入库/出库单中选择

### 2.2 仓库管理

**功能说明**：维护仓库信息。

**操作步骤**：

1. 点击「基础资料」→「仓库管理」
2. 查看仓库列表（编码、名称、容量等）
3. **新增仓库**：点击「新增」→ 填写仓库编码、名称、容量(吨)、位置 → 点击「保存」
4. **编辑仓库**：点击「编辑」→ 修改 → 「保存」
5. **启用/停用**：点击状态开关

**常见错误**：

| 错误现象     | 可能原因             | 解决方法                         |
| ------------ | -------------------- | -------------------------------- |
| 仓库编码重复 | 编码已存在           | 更换编码                         |
| 容量填写错误 | 输入非数字或负数     | 填写正数，如 100.5 表示 100.5 吨 |
| 无法停用仓库 | 仓库有库存或关联单据 | 先清空库存、处理完关联单据       |

**注意事项**：

- 仓库容量用于库存预警，按实际填写
- 停用的仓库无法在出入库单中选择

### 2.3 供应商管理

**功能说明**：维护供应商信息，用于入库单选择供应商。

**操作步骤**：

1. 点击「基础资料」→「供应商管理」
2. **新增供应商**：点击「新增」→ 填写编码、名称、类型、联系人、电话 → 「保存」
3. **编辑/启用/停用**：与商品管理操作一致

**常见错误**：

| 错误现象       | 可能原因     | 解决方法       |
| -------------- | ------------ | -------------- |
| 供应商编码重复 | 编码已存在   | 更换编码       |
| 无法选择供应商 | 供应商被停用 | 联系管理员启用 |

**注意事项**：

- 供应商类型按实际选择（生产商、经销商、代理商等）
- 入库单创建时必须选择供应商

### 2.4 客户管理

**功能说明**：维护客户信息，用于出库单选择客户。

**操作步骤**：

1. 点击「基础资料」→「客户管理」
2. **新增客户**：点击「新增」→ 填写编码、名称、地址、联系人、电话、信用额度、客户等级 → 「保存」
3. **编辑/客户分级**：设置客户等级（A/B/C 级）

**常见错误**：

| 错误现象         | 可能原因   | 解决方法                         |
| ---------------- | ---------- | -------------------------------- |
| 信用额度格式错误 | 输入非数字 | 填写数字，如 100000 表示 10 万元 |
| 客户等级无法修改 | 权限不足   | 联系管理员                       |

**注意事项**：

- 客户地址用于出库单自动填充
- 信用额度用于控制赊销，超限需审批
- A 级客户为重要客户，优先处理

## 3. 入库管理

> 入库单状态流转：**草稿 → 待审核 → 已审核 → 已完成 → 已取消**

### 3.1 新建入库单

**功能说明**：创建新的货物入库记录。

**操作步骤**：

1. 点击「入库管理」→「新建入库单」
2. 填写主表信息：
   - 选择「仓库」（必填）
   - 选择「供应商」（必填）
   - 填写「入库日期」（默认当天）
   - 填写「车号」（必填）
   - 填写「柜号」「来货单号」「备注」（可选）
3. 添加明细：
   - 点击「添加明细」
   - 选择「产品」
   - 填写「入库件数」（必填，> 0）
   - 填写「入库吨位」（必填，> 0）
   - 重复添加所有货品
4. 保存单据：
   - 点击「保存草稿」暂存（可继续编辑）
   - 点击「提交」送审

**常见错误**：

| 错误现象          | 可能原因           | 解决方法                     |
| ----------------- | ------------------ | ---------------------------- |
| 产品选择框为空    | 商品未启用         | 检查商品管理中该商品是否启用 |
| 入库件数/吨位为 0 | 未填写或填 0       | 填写大于 0 的数字            |
| 保存失败          | 必填项为空         | 逐项检查是否遗漏             |
| 提交后无法编辑    | 单据已进入审核流程 | 联系审核员撤销审核后修改     |

**注意事项**：

- 草稿状态单号以 `DRAFT_` 开头，提交后生成正式单号
- 每行明细必须填写件数和吨位
- 车号为必填项，用于追溯车辆信息
- 来货单号建议填写，便于与采购单关联

### 3.2 入库单列表

**功能说明**：查看、搜索、管理所有入库单据。

**操作步骤**：

1. 点击「入库管理」→「入库单列表」
2. 查看列表，显示单号、日期、车号、供应商、状态等
3. **搜索单据**：输入关键词搜索单号、车号、供应商等，或按状态/日期/仓库筛选
4. **查看详情**：点击单据进入详情页
5. **编辑单据**：仅草稿和待审核状态可编辑
6. **删除单据**：仅草稿和待审核状态可删除
7. **导出 Excel**：点击「导出」导出单据数据

**常见错误**：

| 错误现象      | 可能原因               | 解决方法               |
| ------------- | ---------------------- | ---------------------- |
| 搜索无结果    | 关键词不匹配或条件过严 | 扩大搜索范围或清除筛选 |
| 无法编辑/删除 | 单据已审核或已完成     | 联系审核员撤销审核     |
| 导出失败      | 数据量过大             | 分批导出或缩小筛选范围 |

**注意事项**：

- 已审核单据库存已更新，不可直接修改
- 导出 Excel 包含主表和明细信息

### 3.3 入库单详情与审核

**功能说明**：查看入库单详情，审核通过或撤销审核。

**操作步骤**：

1. 从列表点击单据进入详情页
2. 查看主表信息（单号、仓库、供应商、日期等）和明细信息
3. **审核通过**（需审核员权限）：
   - 前提：单据状态为「待审核」
   - 点击「审核通过」→ 确认 → 库存自动增加
4. **撤销审核**（需管理员权限）：
   - 前提：单据状态为「已审核」
   - 点击「撤销审核」→ 确认 → 状态回退至待审核，库存扣减
5. **导出 Excel**：导出详情的完整数据

**常见错误**：

| 错误现象             | 可能原因         | 解决方法                             |
| -------------------- | ---------------- | ------------------------------------ |
| 审核按钮灰色不可点击 | 无权限或状态不符 | 确认审核员角色；确认状态为「待审核」 |
| 审核失败             | 系统异常         | 联系技术支持                         |
| 撤销审核失败         | 无管理员权限     | 联系管理员操作                       |

**注意事项**：

- 审核操作不可逆，审核前务必核对单据信息
- 审核后库存自动更新，触发预警检查
- 撤销审核需管理员权限，谨慎操作

## 4. 出库管理

> 出库单状态流转：**草稿 → 待审核 → 已审核 → 已完成 → 已取消**

### 4.1 新建出库单

**功能说明**：创建新的货物出库记录。

**操作步骤**：

1. 点击「出库管理」→「新建出库单」
2. 填写主表：
   - 选择「仓库」（必填）
   - 选择「客户」（必填，自动带出客户信息）
   - 填写「出库日期」（默认当天）
   - 填写「车号」（必填）
   - 填写「柜号」「合同号」「备注」（可选）
3. 添加明细：
   - 点击「添加明细」
   - 选择「产品」，系统自动显示该产品在当前仓库的库存
   - 填写「出库件数」「出库吨位」（必填，> 0）
   - 如出库数量超过库存，系统标红提示「不足」
   - 重复添加所有货品
4. 保存单据：草稿或提交送审

**常见错误**：

| 错误现象       | 可能原因             | 解决方法                             |
| -------------- | -------------------- | ------------------------------------ |
| 库存不足       | 出库数量大于当前库存 | 减少数量；检查其他仓库库存；等待补货 |
| 客户选择框为空 | 客户未启用           | 检查客户管理中该客户是否启用         |
| 无法选择产品   | 产品在所选仓库无库存 | 更换仓库或先入库该产品               |

**注意事项**：

- 出库单必须选择客户
- 库存不足时无法提交，必须调整数量
- 合同号建议填写，便于与销售合同关联

### 4.2 出库单列表

操作方式与入库单列表一致。搜索支持单号、车号、客户、产品等关键词。

**注意事项**：

- 已审核单据库存已扣减，不可直接修改

### 4.3 出库单详情与审核

**功能说明**：查看出库单详情，审核出库并扣减库存。

**操作步骤**：

1. 从列表点击单据进入详情页
2. **审核通过**（审核员权限）：
   - 前提：状态为「待审核」且库存充足
   - 系统二次校验库存，不足则审核失败
   - 审核后状态变为已审核，库存自动扣减
3. **撤销审核**（管理员权限）：
   - 撤销后状态回退至待审核，库存加回

**常见错误**：

| 错误现象             | 可能原因                 | 解决方法             |
| -------------------- | ------------------------ | -------------------- |
| 审核时提示库存不足   | 提交后库存被其他单据占用 | 调整出库数量重新提交 |
| 撤销审核后库存未加回 | 系统异常                 | 联系技术支持         |

**注意事项**：

- 出库审核严格检查库存，确保不会超发
- 审核前务必核对客户信息和出库数量

## 5. 库存管理

### 5.1 库存查询

**功能说明**：查询各仓库的商品库存及预警状态。

**操作步骤**：

1. 点击「库存管理」→「库存查询」
2. 查看库存列表（产品、仓库、库存件数/吨位、预警状态）
3. **筛选**：按仓库、产品、预警状态筛选
4. **查看流水**：点击产品进入库存流水页面
5. **预警标识**：
   - 绿色「正常」—— 库存在正常范围
   - 红色「低库存」—— 低于最低预警值
   - 黄色「高库存」—— 高于最高预警值
   - 灰色「零库存」—— 库存为 0

**常见错误**：

| 错误现象   | 可能原因                 | 解决方法                 |
| ---------- | ------------------------ | ------------------------ |
| 库存为 0   | 无入库记录或入库单未审核 | 检查入库单状态           |
| 预警不准确 | 预警值未设置或设置不当   | 在商品管理中调整预警阈值 |

**注意事项**：

- 库存数据实时更新，但可能有短暂延迟
- 低库存需及时补货，高库存需控制入库
- 零库存产品需评估是否需要采购

### 5.2 库存调整

**功能说明**：手动调整库存数量（用于盘点差异、损坏报损等）。

**操作步骤**：

1. 在库存查询页面找到需调整的产品
2. 点击「调整」按钮（需 `stock:edit` 权限）
3. 填写调整信息：调整类型（增加/减少）、件数、吨位、调整原因
4. 点击「确认调整」
5. 系统更新库存并记录调整流水

**常见错误**：

| 错误现象       | 可能原因             | 解决方法     |
| -------------- | -------------------- | ------------ |
| 调整后库存为负 | 减少数量超过当前库存 | 检查调整数量 |
| 无调整权限     | 角色权限不足         | 联系管理员   |

**注意事项**：

- 调整原因必须填写，便于追溯
- 调整记录在库存流水可查
- 减少库存时确保不会导致负库存

## 6. 盘点管理

> 盘点单状态流转：**草稿 → 已确认 → 已调整 → 已作废**

### 6.1 新建盘点单

**功能说明**：创建盘点任务，核对实际库存与系统库存。

**操作步骤**：

1. 点击「盘点管理」→「新建盘点单」
2. 选择「仓库」→ 点击「加载库存」
3. 系统显示该仓库所有产品的当前库存
4. 在「实盘件数」「实盘吨位」列填写实际清点数量
5. 系统自动计算差异
6. 点击「确认盘点」提交盘点结果

**常见错误**：

| 错误现象     | 可能原因             | 解决方法                         |
| ------------ | -------------------- | -------------------------------- |
| 加载库存为空 | 所选仓库无库存商品   | 检查仓库选择；确认是否有入库记录 |
| 无法确认盘点 | 有产品未填写实盘数量 | 补充所有产品数据，无库存填 0     |

**注意事项**：

- 盘点前确保所有出入库单据已审核
- 实盘数量必须现场清点，确保准确
- 差异为正 = 盘盈（实际 > 系统），为负 = 盘亏

### 6.2 盘点单列表

查看、搜索盘点单。草稿状态可确认；已确认状态管理员可调整库存或作废。

### 6.3 盘点单详情与库存调整

**操作步骤**：

1. 从列表点击进入详情页
2. 查看盘点明细和差异汇总
3. **调整库存**（管理员权限）：根据实盘数量更新系统库存，状态变为「已调整」
4. **作废盘点单**（管理员权限）：作废不调整库存

**注意事项**：

- 调整库存前确保盘点数据准确
- 差异过大需分析原因（盘点错误、损坏、系统错误等）

## 7. 统计报表

### 7.1 月度出入库汇总

**功能说明**：按月统计入库、出库数量及重量。

**操作步骤**：

1. 点击「统计报表」→「月度出入库汇总」
2. 选择统计年份
3. 查看月度数据：入库单数/重量、出库单数/重量、净入库重量
4. 查看柱状图对比
5. 可导出 Excel

### 7.2 商品周转率统计

**功能说明**：分析商品周转情况，识别滞销和畅销商品。

**操作步骤**：

1. 点击「统计报表」→「商品周转率统计」
2. 选择统计周期（本月/本季/本年或自定义）
3. 查看商品周转率列表（周转率 = 出库量 ÷ 平均库存）
4. 按周转率排序，识别高/低周转商品
5. 导出 Excel

**注意事项**：

- 周转率越高 = 流转越快
- 高周转商品需保证库存充足
- 低周转商品需促销或减少采购

### 7.3 入库/出库明细报表

按日期范围、仓库、供应商/客户、产品等条件查询出入库明细，支持导出 Excel。

### 7.4 库龄分析报表

**功能说明**：分析库存存放时间，识别呆滞库存。

**操作步骤**：

1. 点击「统计报表」→「库龄分析」
2. 选择分析日期和仓库 → 点击「分析」
3. 查看库龄分段（0-30 天、31-90 天、91-180 天、181-365 天、> 365 天）
4. 重点关注库龄 > 180 天的呆滞库存

## 8. 权限管理

### 8.1 用户管理

**功能说明**：管理系统用户账号，分配角色。（需管理员权限）

**操作步骤**：

1. 点击「权限管理」→「用户管理」
2. **新增用户**：点击「新增」→ 填写用户名、密码、姓名、手机、邮箱 → 选择角色 → 点击「保存」
3. **编辑/重置密码/启用禁用**：在列表中操作

**注意事项**：

- 忘记密码需联系管理员重置
- 禁用账号保留数据，删除账号清除关联数据
- 定期清理长期未登录的账号

### 8.2 角色管理

**功能说明**：定义系统角色，分配菜单和操作权限。（需管理员权限）

**系统预置角色**：

- **管理员**：所有权限
- **审核员**：出入库审核权限
- **操作员**：基础操作权限（入库、出库、库存查询）

**操作步骤**：

1. 点击「权限管理」→「角色管理」
2. **新增自定义角色**：填写编码、名称 → 勾选可访问的菜单和操作权限 → 保存
3. **编辑角色权限**：修改权限勾选后保存

**注意事项**：

- 删除角色前确保无用户关联
- 权限分配支持树形展开

## 9. 系统配置

### 9.1 数据字典

**功能说明**：管理系统中的固定选项数据（单据类型、客户等级等）。（需管理员权限）

**操作步骤**：

1. 点击「系统配置」→「数据字典」
2. 管理字典类型和字典项
3. 字典项排序决定下拉框显示顺序

**注意事项**：

- 系统预置字典不可删除
- 禁用的字典项不在下拉框中显示
- 修改字典影响所有使用该字典的页面

### 9.2 系统参数

**功能说明**：配置系统运行参数（预警阈值等）。（需管理员权限）

**操作步骤**：

1. 点击「系统配置」→「系统参数」
2. 按分组筛选参数
3. 修改参数值后点击「保存」
4. 部分参数需刷新页面后生效

**注意事项**：

- 修改前确认参数含义和格式要求
- 重要参数修改前备份原值

### 9.3 单据编号配置

**功能说明**：自定义各类型单据的编号规则。（需管理员权限）

**操作步骤**：

1. 点击「系统配置」→「单据编号配置」
2. 修改规则：前缀、日期格式、流水号长度等
3. 保存后新单据按新规则生成编号

**注意事项**：

- 修改规则不影响已生成的单据
- 修改前请测试规则，避免生成重复编号

## 10. 系统监控

### 10.1 操作日志

**功能说明**：查看所有用户的操作记录，用于审计和排查。（需管理员或审核员权限）

**操作步骤**：

1. 点击「系统监控」→「日志管理」
2. 选择日志类型（登录日志/操作日志）
3. 设置查询条件：时间范围、用户、模块、状态等
4. 查看日志列表，支持导出 Excel

**注意事项**：

- 日志有保留期限，过期自动清理
- 审核、删除、权限变更等重要操作详细记录

### 10.2 在线用户

**功能说明**：查看当前在线用户，支持强制下线。（需管理员权限）

**操作步骤**：

1. 点击「系统监控」→「在线用户」
2. 查看在线用户列表（用户名、登录时间、IP 等）
3. **强制下线**：点击「强制下线」踢出异常用户

**注意事项**：

- 强制下线会中断用户正在进行的操作
- 会话超时时间可在系统参数中配置

## 11. 消息中心

**功能说明**：接收系统通知、预警消息和审核提醒。

**操作步骤**：

1. 点击「消息中心」
2. 查看消息列表（类型：通知、提醒、预警、公告）

**注意事项**：

## 12. 个人中心

### 12.1 修改密码

**操作步骤**：

1. 点击右上角用户头像 →「个人中心」
2. 选择「修改密码」标签页
3. 输入原密码、新密码（8 位以上，含字母和数字）、确认新密码
4. 点击「确认修改」
5. 修改成功后需重新登录

**常见错误**：

| 错误现象         | 可能原因         | 解决方法                       |
| ---------------- | ---------------- | ------------------------------ |
| 原密码错误       | 输入错误或忘记   | 仔细输入；如忘记联系管理员重置 |
| 两次新密码不一致 | 确认密码输入错误 | 重新输入确保一致               |

### 12.2 个人信息

**操作步骤**：

1. 点击右上角用户头像 →「个人中心」→「基本信息」
2. 可修改字段：姓名、手机、邮箱
3. 不可修改字段：用户名、角色（需管理员修改）
4. **上传头像**：点击头像区域选择图片上传（支持 JPG/PNG，不超过 2MB）

**常见错误**：

| 错误现象     | 可能原因             | 解决方法                    |
| ------------ | -------------------- | --------------------------- |
| 头像上传失败 | 图片过大或格式不支持 | 压缩图片；使用 JPG/PNG 格式 |
| 信息保存失败 | 手机/邮箱格式错误    | 检查输入格式是否正确        |

## 14. 故障处理

### 常见问题自助解决

1. **页面无法加载**：检查网络 → 刷新（F5）→ 清除浏览器缓存 → 换 Chrome 浏览器
2. **操作失败提示错误**：记录错误信息 → 检查输入数据 → 重试 → 如重复失败联系技术支持
3. **数据不一致**：刷新页面 → 检查相关单据状态 → 查看库存流水确认变更记录

### 联系技术支持

1. **准备信息**：问题描述、相关单据号/产品编码、错误提示内容、浏览器 F12 控制台截图
2. **联系方式**：联系 IT 部门或系统管理员
3. **问题跟踪**：记录工单号，跟进处理进度
